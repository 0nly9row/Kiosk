# 정의
- 멤버를 특정 객체에 속하게 하는 대신 
클래스 자체에 속하게 만드는 한정자(modifier)이다.
→ 클래스 내부에서는 어떤 곳에서든지 static멤버에 접근이 가능하다.

즉, 해당 클래스 자체에만 속한 것.
- 객체에 속한 멤버가 아님.

[일반 메서드]
- 객체 생성 
  → 객체를 통해 메서드 호출 
  → 필요하면 객체의 상태 사용

[static 메서드]
- 객체 생성 필요 없음 
  → 클래스명을 통해 바로 호출
- 예시
GraphicsUtil.GetRoundedRectanglePath( rect, radius );

# static의 핵심 판단 기준
- 공용으로 사용한다고 해서 무조건 static인 것은 아니다.
- 현재 경로 계산 메서드는 아래와 같은 이유로 적합하다
1.  객체별 상태가 필요하지 않음
2.  필요한 값을 매개변수로 모두 받음
3.  계산 결과만 반환함
4.  여러 곳에서 같은 계산을 사용할 수 있음
